# my-portfolio

Personal portfolio website — auto-generated and pushed from the design studio.

## Deploy

### GitHub Pages (free)
1. Go to repo Settings → Pages
2. Source: Deploy from a branch → `main` → `/ (root)`
3. Your site will be live at `https://<username>.github.io/my-portfolio/`

### Vercel / Netlify
1. Import this repo in Vercel/Netlify dashboard
2. No build step needed — just serve static files
3. Framework preset: Other

## Update
Re-push from the design studio to update the site content.
